# Keyword map

Search demand the site is built to meet, and the page that meets it.

## Method

- **Source:** Google Autocomplete (US English), collected 2026-09-30 from 151 seed queries across our services, industries and AI
  search. Autocomplete returns what people actually type; it gives **no search volumes**, so it proves demand exists but not
  how much. Pair this map with Search Console (real impressions and clicks, once the site is live) or a keyword tool before
  ranking the backlog by size.
- **Collected:** 1067 unique suggestions after removing other
  countries and obvious noise; 635 are questions. Raw data: `autocomplete-2026-09-30.json`.
- **Rule:** one page owns one primary query. Close variants (same intent) are that page's secondary queries, so pages never
  compete with each other.
